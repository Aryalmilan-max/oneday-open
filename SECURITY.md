# Security policy

Please do not publish exploit details or private data in an issue. Open a GitHub private vulnerability report for this repository if the feature is available, or contact the maintainer through the contact information on the GitHub profile.

OneDay treats pasted text and selected files as untrusted. Result text should be rendered as text, and any HTML result must escape user content. Link inspection is informational, not a malware or phishing verdict. Third-party browser libraries are pinned to specific versions, and external-service calls must remain opt-in and visible in the tool description.

The project is in public beta. Security reports are welcome; no response-time guarantee is offered.
