YOUR DATA, YOUR CHOICE

No account needed.
No hidden upload.

Notes, tasks, reminders, and expenses are stored in this browser. Translation sends the entered text to MyMemory; exchange rates query ExchangeRate-API; OCR and PDF tools download open-source browser libraries. These online actions run only after you select them. This browser storage is not encrypted—avoid saving secrets on shared devices.
