# Roadmap

The public beta provides 27 focused actions, a browser-based conversation guide, and a local day dashboard. The next work is quality and depth, based on real feedback.

## Next

- Add realistic browser integration tests for key cross-tool flows.
- Improve guide intent coverage and clarify ambiguous requests without guessing.
- Add localization infrastructure and reviewed translations.
- Improve date and amount extraction for more scripts and formats.
- Improve saved-data search, edit, and import with conflict handling.
- Replace CDN runtime dependencies with reproducible, self-hosted builds where practical.
- Make online tool availability visible before a user fills a form.
- Improve offline capability for file-processing tools.

## Later, if users need it

- Optional sync controlled by the user.
- Mobile share-target integration and install guidance.
- Additional browser-supported OCR languages.
- Optional integrations with user-selected calendars and storage providers.

## Product boundary

No hidden data collection, fabricated fact-checking verdicts, automatic financial advice, or claims of guaranteed adoption.
